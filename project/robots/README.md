# Robot modeling references

Only Jaguar and Shadow are in the current 3D modeling scope.

| Robot | Approved three-view set | Accepted prototype blockout | Earlier concepts |
| --- | --- | --- | --- |
| Jaguar | [Front, back, and right side](jaguar/canonical/README.md) | [Editable mesh and review renders](jaguar/blockout/README.md) | [Front exploration](jaguar/front/README.md) |
| Shadow | [Front, back, and right side](shadow/canonical/README.md) | [Editable mesh and review renders](shadow/blockout/README.md) | [Front exploration](shadow/front/README.md) |

The blockout silhouettes were accepted for the prototype milestone on
2026-10-14. Use the canonical folders for further modeling; the blockouts are
editable rigid-part meshes rather than final surfaced or skinned assets. The
concept folders and side-view drafts record how the designs evolved. Original
game sprites are generated locally in [the OMF2097 pose gallery](../docs/OMF2097/poses/index.md);
matched higher-resolution frames are in [the Remastered gallery](../docs/Remastered/poses/index.md).
