# Jaguar front-view redesigns

For designs closer to the original robot, see the [five faithful revisions](faithful-v2/README.md).

Five image-to-image concept variants based on Jaguar's original mostly frontal
victory frame and idle sprite from `FIGHTR0.AF`. Each asks for a full-body,
orthographic front view in a neutral pose, with silver-gray armor, green optics,
angular feline head shapes, broad shoulders, and a transparent background.

| Version | Direction | Image |
| --- | --- | --- |
| 1 | Faithful remaster: preserve the original proportions and silhouette while clarifying layered armor and joints | ![Faithful remaster](01-faithful-remaster.png) |
| 2 | Sleek striker: lighter, sharper armor and a faster athletic silhouette | ![Sleek striker](02-sleek-striker.png) |
| 3 | Heavy champion: reinforced chest, shoulders, gauntlets, and leg protection | ![Heavy champion](03-heavy-champion.png) |
| 4 | Retro industrial: stamped plates, fasteners, pistons, access panels, and subtle wear | ![Retro industrial](04-retro-industrial.png) |
| 5 | Elite prototype: refined ceramic-metal panels, tapered V-shaped chest, selective green circuitry | ![Elite prototype](05-elite-prototype.png) |

These are exploration images. Before building a 3D model, choose one direction
and draw a consistent side, back, and three-quarter turnaround with matching
joint and armor construction.
